# PRD Creator スキル

**PBI（Product Backlog Item）から最高品質のPRDを作成**するスキルです。

## コンセプト

1. **PBIを入力として受け取る**
2. **PRDとして足りない情報を特定**
3. **徹底的な質問で深掘り**
4. **「〇〇がXXできる」形式でPRDを生成**

## 使い方

```
/prd-creator
```

**入力方法:**
- PBIのテキストを貼り付け
- Jira/NotionのURLを共有
- スクリーンショット添付
- 口頭で説明

## 深掘りポイント

| カテゴリ | 深掘り内容 |
|---------|-----------|
| 基本要素 | 誰が・何を・どうする・どうなる |
| 入力・出力 | 入力項目、バリデーション、出力形式 |
| 制約条件 | 件数制限、時間制限、権限 |
| エラー | エラー種類、表示、リトライ |
| エッジケース | 0件、大量データ、同時操作 |
| 既存機能 | 影響、互換性、マイグレーション |
| UI/UX | 配置、フロー、フィードバック |
| スコープ外 | 今回含めない機能の明確化 |

## 出力言語

**日本語版と英語版の両方**を出力します。

## 生成されるPRD

```markdown
# [機能名] - Product Requirements Document

## 1. 概要
## 2. 背景と目的
## 3. ユーザーストーリー
## 4. 機能要件（「〇〇がXXできる」形式）
## 5. 非機能要件
## 6. 変更履歴
```
