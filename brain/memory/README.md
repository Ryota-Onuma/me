# AIネイティブ・Zettelkasten

最高の知的生産環境を実現するナレッジベースシステム。

## ディレクトリ構成

| ディレクトリ | 役割 | Git管理 |
|---|---|---|
| `01-Fleeting-Notes/` | 走り書き。未整理のアイデアやメモを投入 | ✅ 対象 |
| `01-Fleeting-Notes/Secret/` | プライベートな走り書き | ❌ **除外** |
| `02-Permanent-Notes/` | 永久メモ。原子的な知識カード（アトミックノート） | ✅ 対象 |
| `02-Permanent-Notes/Secret/` | プライベートな永久メモ | ❌ **除外** |
| `03-Structured-Notes/` | 構造化ノート。プロジェクト別のワーキングノート | ✅ 対象 |
| `90_System/` | システムツール（Gardener Web等） | ✅ 対象 |

## Zettelkastenワークフロー

```
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│ 01-Fleeting     │───▶│ 02-Permanent     │───▶│ 03-Structured    │
│ (走り書き)       │    │ (永久メモ)        │    │ (構造化ノート)    │
└─────────────────┘    └──────────────────┘    └──────────────────┘
```

## Secretルール

- どの階層でも `Secret/` フォルダの中身は `.gitignore` により完全除外
- プライベートなメモを安全に保管可能
