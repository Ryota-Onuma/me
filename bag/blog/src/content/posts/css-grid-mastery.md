# CSS Grid Mastery

CSS Grid has revolutionized web layout design.

## Basic Grid Setup

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}
```

## Responsive Grids

Use `minmax()` for flexible responsive designs.
